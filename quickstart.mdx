This is the full procedure. Each step says who does it.

**You need:** an Android `.apk` and Python 3.8 or later. People can hand all of this to a coding agent:

```text
Enable my app on nowrun using the nowrun CLI. For the full steps, read https://nowrun.io/docs/skill.md
```

## 1. Create an account (human)

Sign up at [nowrun.io](https://nowrun.io) and verify a card. It is a $0 check, not a charge.

## 2. Install and sign in (agent, then human)

```bash
pip install nowrun
nowrun login
```

`nowrun login` prints a sign-in link and opens a browser. The human approves it. The link is valid for about five minutes.

**Done when:** `nowrun whoami` shows the account.

## 3. Collect the listing (human answers, agent records)

Ask the human for a description, a one-line pitch and two to four example requests. Do not invent them. Rules and limits: [Describe your app](/deploying/describe-your-app).

## 4. Create the app (agent)

```bash
nowrun app create --from-apk app.apk \
  --title "Recipe Box" --category "<from nowrun app categories>" \
  --description "Save recipes and turn them into a shopping list." \
  --pitch "Go from recipe to shopping list in one step." \
  --intent "What can I make with chicken and rice?" \
  --intent "Add these ingredients to my list" \
  --kind app --orientation portrait
```

`--from-apk` reads the package name and icon from the build. Run `nowrun app categories` for the category list. The new app is linked to the current folder, so later commands don't need `-a`.

**Done when:** the command returns an `app_id`. If fields are missing, it lists them.

## 5. Deploy (agent)

```bash
nowrun deploy -f app.apk --wait
```

**Done when:** `job_status` is `success`. If it is `failed`, see [Deploy and open](/deploying/your-first-deploy#if-the-deploy-fails).

## 6. Open it (human)

With the [nowrun plugin](/install-the-plugin) connected, the human asks for the app by name in ChatGPT and taps **Open**. The app is private to them and needs no install step.
