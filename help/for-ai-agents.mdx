nowrun is built to be driven by AI coding agents. This page lists every agent-facing endpoint the docs site exposes, so an agent can find, search and act on the docs without any setup.

## Content indexes

<Card title="/llms.txt" icon="file-text" href="https://nowrun.io/docs/llms.txt">
  A concise index of every page in the docs, formatted for LLMs. Follows the [llmstxt.org](https://llmstxt.org) convention.
</Card>

<Card title="/llms-full.txt" icon="file-lines" href="https://nowrun.io/docs/llms-full.txt">
  The full contents of the docs as a single markdown file. Use it when you want everything in one file.
</Card>

<Card title="Any page as markdown" icon="code" href="https://nowrun.io/docs/quickstart.md">
  Append `.md` to any docs URL to get the raw markdown for that page (for example, `/quickstart.md`).
</Card>

## MCP server

The docs expose a hosted Search MCP server so agents can search the current docs instead of relying on old training data.

| Endpoint | Purpose |
| --- | --- |
| `https://nowrun.io/docs/mcp` | Search MCP server. Add this URL to any MCP-compatible client. |
| `https://nowrun.io/docs/.well-known/mcp` | MCP discovery document. Agents check this to locate the server automatically. |
| `https://nowrun.io/docs/.well-known/mcp.json` | Same discovery document, JSON extension. |
| `https://nowrun.io/docs/.well-known/mcp/server-card.json` | MCP server card with tool metadata (name, description, input schema). |
| `https://nowrun.io/docs/.well-known/mcp/server-cards.json` | List of server cards for this deployment. |

Connect from your client of choice:

<CodeGroup>

```bash Claude Code
claude mcp add --transport http nowrun https://nowrun.io/docs/mcp
```

```json Cursor (mcp.json)
{
  "mcpServers": {
    "nowrun": {
      "url": "https://nowrun.io/docs/mcp"
    }
  }
}
```

```toml Codex (~/.codex/config.toml)
[mcp_servers.nowrun]
url = "https://nowrun.io/docs/mcp"
```

```json VS Code (.vscode/mcp.json)
{
  "servers": {
    "nowrun": {
      "type": "http",
      "url": "https://nowrun.io/docs/mcp"
    }
  }
}
```

</CodeGroup>

## Skills

Start with [skill.md](https://nowrun.io/docs/skill.md): it walks an agent through adding an app to nowrun. `nowrun login` then installs the full skill and docs MCP server locally. See [nowrun login](/cli/login).

## Supported input formats

nowrun accepts Android `.apk` files. Android App Bundles (`.aab`) and iOS builds aren't supported. If your engine produces an `.aab`, set it to output an `.apk` before running `nowrun deploy`.

## What's safe to share

These endpoints only expose content already published on this site. There are no tokens, secrets or private data behind them.
