<AccordionGroup>

<Accordion title="What do I need?">
  A nowrun account, an Android `.apk`, and Python 3.8 or later. A coding agent is optional but faster.
</Accordion>

<Accordion title="Who can see my app?">
  Only you. New apps are private.
</Accordion>

<Accordion title="Do I need app functions?">
  No. Every app can be opened and seen. App functions let the assistant act inside your app. See [App functions](/sdk/app-functions).
</Accordion>

<Accordion title="Do users install anything?">
  No. Apps run on nowrun and stream into the chat.
</Accordion>

<Accordion title="Why verify a card for the free plan?">
  It prevents abuse. The $0 check is not a charge, and you stay on the free plan until you upgrade.
</Accordion>

<Accordion title="Do I need an API token?">
  No. `nowrun login` signs you in through the browser.
</Accordion>

<Accordion title="Can I use the CLI without an agent?">
  Yes. Follow [Add your app](/quickstart) yourself.
</Accordion>

</AccordionGroup>
