<AccordionGroup>

<Accordion title="nowrun: command not found after installing">
  The package installed, but Python's scripts folder isn't on your `PATH`. Run `pip show nowrun` to find where it installed. The `nowrun` command is in the `bin` folder next to the reported location (on macOS system Python, `~/Library/Python/3.x/bin`). Add that folder to your `PATH`, or call the command by its full path.
</Accordion>

<Accordion title="nowrun login times out">
  The sign-in link is valid for about five minutes. Run `nowrun login` again for a fresh one.
</Accordion>

<Accordion title="app create says fields are missing">
  Every app needs a title, package name, category, description, pitch, at least one request (`--intent`), kind, orientation and icon. Run `nowrun validate` to see what's missing. See [Describe your app](/deploying/describe-your-app).
</Accordion>

<Accordion title="Deploy is rejected">
  Check that your build is an `.apk` (not an `.aab`) and that its package name matches your app. `nowrun inspect app.apk` shows the build's package name and version.
</Accordion>

<Accordion title="My app doesn't open in the chat">
  Check the [nowrun plugin](/get-the-plugin) is connected with the same nowrun account you deployed with, and that `nowrun status` shows the deploy succeeded.
</Accordion>

<Accordion title="My agent doesn't know how to use nowrun">
  The nowrun skill is installed by `nowrun login`. Run it again, then ask your agent to retry.
</Accordion>

</AccordionGroup>
