---
title: "Sign in to the nowrun CLI"
sidebarTitle: "Sign in"
description: "Run nowrun login to sign the CLI in through your browser. It also sets up your coding agent with the nowrun skill and docs MCP server."
---

```bash
nowrun login
```

The CLI opens your browser. Approve the sign-in while logged in to your nowrun account, and the CLI picks it up. There's no token to copy.

`nowrun login` also installs the nowrun skill and the docs MCP server for your coding agent, so it knows how to use nowrun from then on.

## If your agent runs it

Your agent can't approve the sign-in for you. It runs `nowrun login`, shows you the link and waits. Once you approve, it carries on. The link is valid for about five minutes. If it expires, run `nowrun login` again.

## No browser on this machine?

`nowrun login` prints the link before it opens anything. On a server or over SSH, open the link on your phone or another computer and approve it there.

## Check or end your session

```bash
nowrun whoami    # who is signed in
nowrun logout    # sign out on this machine
```

You stay signed in for 30 days after you last use the CLI.
