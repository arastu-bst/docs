Your coding agent usually installs the CLI for you. To do it yourself, you need Python 3.8 or later.

```bash
pip install nowrun
```

Check it worked:

```bash
nowrun help
```

To update the CLI, its agent skill and the docs MCP server later:

```bash
nowrun update
```
