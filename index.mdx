nowrun runs Android apps inside ChatGPT. People open an app in the chat, the assistant can see its screen, and with app functions it can act inside the app for them.

Building for nowrun has two parts:

<CardGroup cols={2}>
  <Card title="1. Add your app" icon="terminal" href="/quickstart">
    Put your Android app on nowrun with the nowrun CLI.
  </Card>
  <Card title="2. Add app functions" icon="bolt" href="/sdk/app-functions">
    Expose actions with the nowrun SDK so the assistant can run them inside your app.
  </Card>
</CardGroup>

To open apps, you need the nowrun plugin connected to your ChatGPT account: [Get the plugin](/get-the-plugin).

## For coding agents

Start with [skill.md](https://nowrun.io/docs/skill.md). It is the complete procedure for adding an app. People can hand their agent this line:

```text
Enable my app on nowrun using the nowrun CLI. For the full steps, read https://nowrun.io/docs/skill.md
```
