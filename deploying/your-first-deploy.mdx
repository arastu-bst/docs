## Deploy

```bash
nowrun deploy -f app.apk --wait
```

The CLI reads the version from the APK and refuses a build whose package name doesn't match the app.

With `--json`, the result is:

```json
{"ok": true, "data": {"submission_id": "…", "job_status": "success", "app_testing_url": "…"}}
```

**Done when:** `job_status` is `success`.

## If the deploy fails

| Symptom | Do this |
| --- | --- |
| `job_status` is `failed` | Read the error message, fix the build, deploy again. |
| Fields missing | Run `nowrun validate` and set what it lists with `nowrun app update`. |
| Package mismatch | Run `nowrun inspect app.apk` and check the package name matches the app. |
| `.aab` file | Rebuild as `.apk`. See [Supported builds](/deploying/supported-engines). |
| Not signed in | Run `nowrun login` and have the human approve it. |

Don't redeploy while a deploy is in progress. Check with `nowrun status`.

## Open the app (human)

1. Connect the [nowrun plugin](/get-the-plugin) in ChatGPT, if not done already.
2. Ask for the app by name.
3. Tap **Open**.

The app is private to its owner and is already in their container, so there is no **Search and install** step.

## Check it works

- Ask one of the app's requests and check the app is chosen.
- With the app open, ask `What do I do now?` and check the answer matches the screen.
- If the app has [app functions](/sdk/app-functions), ask for those actions and check they run.
