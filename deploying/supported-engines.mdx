nowrun runs Android apps from any engine that outputs an `.apk`:

- **Native Android** (Android Studio and Gradle)
- **Unity** (IL2CPP or Mono)
- **Godot**
- **Unreal Engine**

Debug and release APKs both work. `armeabi-v7a`, `arm64-v8a` and `x86_64` builds all work, and there's no minimum Android API level.

## App bundles aren't supported

nowrun needs an `.apk`, not an `.aab` (Android App Bundle). If your build outputs an `.aab`:

- **Android Studio:** **Build → Build Bundle(s) / APK(s) → Build APK(s)**
- **Unity:** in **Android Player Settings**, turn off **Build App Bundle (Google Play)**
- **Other engines:** look for an option to export `.apk` instead of `.aab`

iOS builds aren't supported.
