title: "Manage your app"
sidebarTitle: "Managing your app"
description: "Deploy new versions, check status, change details or delete an app with the nowrun CLI."
---

| To | Run |
| --- | --- |
| Deploy a new version | `nowrun deploy -f app.apk --wait` |
| See what's live and in progress | `nowrun status` |
| Check one deploy | `nowrun status -s <submission_id>` |
| Cancel a deploy in progress | `nowrun cancel` |
| List your apps | `nowrun app list` |
| Show one app, its visibility and readiness | `nowrun app show` |
| Check for missing fields | `nowrun validate` |
| Change details | `nowrun app update` |
| Change the icon | `nowrun app set-icon icon.png` |
| Link this folder to an app | `nowrun use <app_id>` |
| Delete an app (permanent) | `nowrun app delete` |

Commands use the app linked to the current folder. Pass `-a <app_id>` to target another.

New apps are private: only the owner can see and open them.
