Your agent handles all of this with the CLI. These are the commands it uses.

| To | Run |
| --- | --- |
| Deploy a new version | `nowrun deploy -f app-release.apk --wait` |
| See what's live and in progress | `nowrun status` |
| Cancel a deploy in progress | `nowrun cancel` |
| List your apps | `nowrun app list` |
| See one app's details and readiness | `nowrun app show` |
| Check what's missing before deploying | `nowrun validate` |
| Change the description, pitch, icon or other details | `nowrun app update` |
| Delete an app | `nowrun app delete` |

Deleting an app is permanent and frees a slot on your plan.

## Who can see your app

New apps are private. Only you can see and open your app in ChatGPT.
