The nowrun CLI is built to be run by your coding agent. `nowrun login` installs a skill that teaches your agent how to use it, and your agent can always ask the CLI for help:

```bash
nowrun help            # every command
nowrun <command> -h    # one command
```

Add `--json` to any command for machine-readable output.

## Commands

| Command | What it does |
| --- | --- |
| `nowrun login` | Sign in through your browser and set up your agent |
| `nowrun whoami` | Show who is signed in |
| `nowrun logout` | Sign out on this machine |
| `nowrun update` | Update the CLI, skill and docs MCP server |
| `nowrun app create` | Create an app with its listing details |
| `nowrun app categories` | List the categories an app can have |
| `nowrun app update` | Change an app's details |
| `nowrun app list` | List your apps |
| `nowrun app show` | Show one app, with its visibility and readiness |
| `nowrun app delete` | Delete an app |
| `nowrun inspect app.apk` | Read a build's package name and version |
| `nowrun validate` | Check what's missing before deploying |
| `nowrun deploy` | Deploy a build |
| `nowrun status` | Show what's live and in progress |
| `nowrun cancel` | Cancel a deploy in progress |

More detail: [nowrun login](/cli/login), [nowrun deploy](/cli/deploy).
