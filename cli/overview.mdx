```bash
nowrun help            # every command and the workflow
nowrun <command> -h    # one command's flags
```

These ship with the CLI, so they always match the installed version.

## Output for scripts and agents

Add `--json` to any command, in any position.

| Result | Output | Exit code |
| --- | --- | --- |
| Success | `{"ok": true, "data": {...}}` | 0 |
| Error | `{"ok": false, "error": {...}}` | 1 |

## Commands

| Command | What it does |
| --- | --- |
| `nowrun login` | Sign in through the browser and set up the agent skill and docs MCP |
| `nowrun whoami` | Show who is signed in |
| `nowrun logout` | Sign out on this machine |
| `nowrun update` | Update the CLI, skill and docs MCP server |
| `nowrun app create` | Create an app with its listing |
| `nowrun app categories` | List valid categories |
| `nowrun app update` | Change an app's details |
| `nowrun app set-icon` | Change an app's icon |
| `nowrun app list` | List your apps |
| `nowrun app show` | Show one app, its visibility and readiness |
| `nowrun app delete` | Delete an app |
| `nowrun use <app_id>` | Link this folder to an app |
| `nowrun inspect app.apk` | Read a build's package name and version |
| `nowrun validate` | List missing fields |
| `nowrun deploy` | Deploy a build |
| `nowrun status` | Show deploy status |
| `nowrun cancel` | Cancel a deploy in progress |

More: [nowrun login](/cli/login), [nowrun deploy](/cli/deploy).
