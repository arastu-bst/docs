```bash
nowrun login
```

1. The CLI prints a sign-in link and opens your browser.
2. You approve it while logged in to nowrun.
3. The CLI saves the session on this machine.
4. It installs the nowrun skill and docs MCP server for your coding agent.

There's no token to copy. The link is valid for about five minutes. If it expires, run `nowrun login` again.

## For AI agents

You can't finish `nowrun login` alone, because a person has to approve it. Run the command, **show the link to the user and wait**. The command returns once they approve.

## Flags

<ParamField path="--target" type="string">
  Which coding tool to set up: `claude` (default), `agents`, `codex`, `copilot`, `cursor` or `vscode`.
</ParamField>

<ParamField path="-d" type="string">
  Project folder to set up the agent in. Defaults to the current folder, so run it from your project.
</ParamField>

## Related

```bash
nowrun whoami    # who is signed in
```
