```bash
nowrun deploy -f app.apk --wait
```

Reads the version from the APK. Refuses a build whose package name doesn't match the app.

## Flags

<ParamField path="-f" type="string" required>
  Path to the `.apk`.
</ParamField>

<ParamField path="-a" type="string">
  App to deploy to. Defaults to the app linked to this folder.
</ParamField>

<ParamField path="--wait" type="boolean">
  Block until the build finishes. Without it, the command returns a `submission_id` to check with `nowrun status -s`.
</ParamField>

<ParamField path="--timeout" type="number">
  Seconds to wait with `--wait`. Default 900.
</ParamField>

## Result

`job_status` is `success` or `failed`. See [If the deploy fails](/deploying/your-first-deploy#if-the-deploy-fails).

For every flag, run `nowrun deploy -h`.
