```bash
nowrun deploy -f app-release.apk --wait
```

`nowrun deploy` uploads your build to the app in your current project. It reads the version from the APK, and refuses a build whose package name doesn't match the app.

## Flags

<ParamField path="-f" type="string">
  Path to your `.apk`.
</ParamField>

<ParamField path="-a" type="string">
  The app to deploy to. Defaults to the app linked to this project.
</ParamField>

<ParamField path="--wait" type="boolean">
  Wait until the build is ready before returning.
</ParamField>

For every option, run `nowrun deploy -h`.

## After deploying

Each deploy is a new version. Check progress with `nowrun status`, then [open your app in ChatGPT](/deploying/your-first-deploy).
